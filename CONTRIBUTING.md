# Contributing to the SAC Website

This guide is for non-technical editors who want to add events, team members, or update site content.

## How to Add an Event

1. Visit [sac.ieeehyd.org/admin/](https://sac.ieeehyd.org/admin/)
2. Click **Login with GitHub** — use your GitHub account (must have access to the repo)
3. In the sidebar, click **Events**
4. Click **New Event**
5. Fill in:
   - **Title** — event name
   - **Date & Time** — when it starts
   - **Venue** — location or "Online"
   - **Mode** — in-person / online / hybrid
   - **Poster Image** — upload the event poster
   - **Short Description** — 1-2 sentence summary
   - **Registration URL** — link to vTools or registration form
   - **vTools Event ID** — just the number from the URL (e.g. `538749`)
   - **Feature on Homepage?** — toggle on for the next big event
6. Click **Save** — this creates a **draft** (a GitHub Pull Request)
7. Share the PR link with the web team lead for review and merge
8. Once merged, the site rebuilds automatically within ~60 seconds

## How to Update Team Members

1. Go to `/admin/` and log in
2. Click **SN Team** or **SAC Core Team** in the sidebar
3. Edit the roster — add, remove, or update members
4. Click **Save** and wait for merge

## How to Update the Homepage Announcement or Hero

1. Go to `/admin/` and click **Homepage & Site Settings**
2. Toggle the **Announcement Bar** on/off, set the text and link
3. Update the hero title, subtitle, or CTA links as needed
4. Save and wait for merge

## Need Help?

Contact the SAC Web Development Team or open an issue on GitHub.
